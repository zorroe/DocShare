# 最佳实践

## 文档目录组织

推荐按主题建文件夹，文件名清晰简短：

```text
docs/
├── README.md          # 项目首页
├── 指南/
│   ├── 使用说明.md
│   └── 最佳实践.md
└── 规范/
    └── 命名规范.md
```

## 写作建议

- 每个文档开头用 `# 标题` 说明主题；
- 使用 `##` 二级标题分段，便于阅读；
- 代码块指定语言以启用语法高亮：```` ```go ````；
- 关键提示用引用块强调：

> [!NOTE]
> 引用块适合放置注意事项。
