# 使用说明

欢迎使用 DocShare 文档中心。本文介绍日常使用方式。

## 浏览文档

1. 在左侧目录树中点击任意 `.md` 文件；
2. 正文区会以 Markdown 格式渲染显示，右侧悬浮大纲可点击跳转章节；
3. 顶部搜索框（或按 `Ctrl+K`）可快速过滤文档；
4. 鼠标悬浮目录树中的文件可查看完整路径。

## 桌面端管理

桌面端（管理员）可：

- **设置**：选择文档目录、端口、局域网开关、IP 黑名单、开机自启动；
- **访问记录**：查看最近 500 条文档浏览记录（时间/文档/来源 IP/浏览器）；
- **托盘**：最小化或关闭窗口后隐藏到系统托盘继续服务，右键托盘图标可「打开」或「退出」。

## 常见问题

- **Q: 为什么看不到我的文档？**
  A: 仅展示 Markdown 文件（`.md` / `.markdown`），隐藏文件会被忽略。
- **Q: 局域网设备无法访问？**
  A: 确认服务以 `-addr 0.0.0.0:端口` 启动，并检查系统防火墙是否放行该端口。
- **Q: 关闭窗口后服务会停吗？**
  A: 不会，关闭/最小化窗口只是隐藏到系统托盘，服务继续运行；托盘「退出」才会完全退出。

## 快捷键

| 快捷键 | 功能 |
| ------ | ---- |
| `Ctrl+K` | 聚焦搜索框 |
| `Esc` | 关闭弹窗 |
| 左下角按钮 | 切换深色/浅色主题 |
