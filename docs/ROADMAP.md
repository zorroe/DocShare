# DocShare 优化路线图

按优先级分四个阶段，每项完成后通过自动化测试并打包验证。

## P0 — 使用价值最高

- [x] **P0-1 全文搜索**：后端轻量倒排索引（中文 bigram + 英文分词），`GET /api/search`；前端搜索框全文匹配结果 + 关键词高亮
- [x] **P0-2 目录树监听刷新**：fsnotify 监听文档目录，增删改自动刷新树；扫描结果缓存

## P1 — 体验与安全

- [x] **P1-1 Markdown 渲染增强**：代码块"复制"按钮、Mermaid 图表、行内代码样式优化
- [x] **P1-2 只读访问密码**：设置面板可选启用，网页端访问需输入密码（session 记忆）
- [ ] **P1-3 文档导出**：单篇导出 HTML/PDF（打印样式）

## P2 — 工程健壮性

- [ ] **P2-1 Go 单测补齐**：store.Resolve 路径穿越变体、黑名单匹配、config 损坏恢复
- [ ] **P2-2 托盘图标**：设计 .ico 嵌入 exe，替换系统默认图标
- [ ] **P2-3 自动更新**：启动时检查 GitHub Release 版本并提示

## P3 — 锦上添花

- [ ] **P3-1 阅读记忆**：最近浏览列表 + 每篇阅读进度恢复
- [ ] **P3-2 多文档根目录**：桌面端可配置多个目录并行展示
- [ ] **P3-3 高亮主题统一**：深浅色共用同一套 highlight token 变量

## 完成标准

- 每项：功能实现 + 自动化测试通过（UI 测试或 Go 单测）+ 三个产物重新打包
- P0/P1 完成后提交一次代码
